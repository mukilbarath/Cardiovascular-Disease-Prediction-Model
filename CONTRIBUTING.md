# Contributing

Use a branch and submit changes for owner review. Run the documented lint, formatting, tests and package build before requesting review. Keep fixtures synthetic and confined to tests; never check in patient data, fitted models or invented results.

Methodology changes must describe the changed protocol and retain a distinction between paper claims and new measurements. Do not optimize against the held-out test set. Add or update meaningful behavior tests when changing validation, splitting, fitting or metrics.

No license has been selected. Ask the owner to establish code and data reuse permissions before redistribution. Publication metadata changes require a verifiable source. Releases, merges, dataset uploads and public publication need owner approval.
